# OrbitTab

Кастомная страница новой вкладки (Speed Dial) для Firefox.

## Возможности
- Часы и дата в реальном времени
- Поисковая строка с выбором поисковиков из настроек Firefox и их логотипами
- Автоматическая генерация фона плиток и подгрузка иконок сайтов
- 4 режима сетки: квадраты, пчелиные соты, 2D-орбиты и 3D-космос
- Живое анимированное перетаскивание плиток
- Настройка фона (пресеты, цвет или своё изображение)
